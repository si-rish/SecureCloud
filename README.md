# SecureCloud

SecureCloud is a Secure Private Cloud Storage and File Management System designed for organizations.

## Project Overview

SecureCloud allows authorized users to securely store, manage, access, and share files within an organization.

The system provides:

- User registration and login
- Role-based access control
- File upload, download, and deletion
- Folder management
- File sharing with permissions
- File version management
- Activity and audit logging
- Multiple storage nodes
- File backup and replication
- REST API
- GraphQL API
- SOAP service integration
- Authentication and authorization
